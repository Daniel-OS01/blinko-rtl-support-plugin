⚡ Bolt: Optimize MutationObserver selector loop matching

💡 What: Replaced iterative `element.matches(selector)` inside a `for` loop with a single `element.matches(joinedSelectors)` evaluation within the `MutationObserver` callback. Also updated github actions to use `oven-sh/setup-bun@v2` instead of `v1` to resolve Node 20 deprecation issues leading to 504 timeout errors.
🎯 Why: In high-frequency DOM manipulation paths (like a `MutationObserver` callback), calling `.matches(s)` iteratively across multiple valid selectors introduces CPU overhead. Evaluating a single combined comma-separated selector (`joinedSelectors`) offloads the loop to the native browser CSS engine, yielding significantly better performance.
📊 Impact: Expected to reduce execution time of the `MutationObserver` callback during frequent DOM updates, limiting main thread blocking.
🔬 Measurement: Run the test suite (`bun test`) to confirm tests still pass, specifically checking performance benchmarks within `tests/detection-benchmark.test.ts`.
