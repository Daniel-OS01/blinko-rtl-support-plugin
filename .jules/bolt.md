## 2023-08-14 - Optimize MutationObserver DOM matching
**Learning:** In high-frequency DOM manipulation paths (like `MutationObserver` callbacks), checking `element.matches(selector)` within a loop over multiple CSS selectors causes CPU overhead. Combining valid selectors into a single comma-separated string (e.g., `selectors.join(', ')`) and evaluating it with a single `.matches(joinedSelectors)` call leverages native browser optimizations. However, care must be taken to pre-validate the individual selectors, as a single invalid selector in the joined string will cause `.matches()` to throw a `SyntaxError` and fail for all other valid selectors.
**Action:** When evaluating multiple CSS selectors against an element in a hot loop, join the valid selectors and use a single `.matches()` call for better performance, ensuring they are safely pre-filtered or catching potential syntax errors appropriately.
