## 2025-02-21 - Prompt Injection via Regex Special Characters in String Replacement
**Vulnerability:** When generating templates dynamically by substituting content (like {note} and {tags}) into a configuration string, `String.prototype.replace(regex, string)` interprets special characters in the replacement string, such as `$'`, `$&`, and `$1`. This allows malicious user content containing these sequences to manipulate the rendered template in unexpected ways.
**Learning:** Even simple string interpolation mechanisms can introduce injection vulnerabilities if they rely on native regular expression string replacements. In applications handling Markdown content, users naturally write strings that include these special tokens.
**Prevention:** When dynamically substituting user content into template strings via `replace`, always use a replacer function (e.g., `replace(/\{note\}/g, () => userContent)`) to guarantee the content is injected literally without regex metadata evaluation.
