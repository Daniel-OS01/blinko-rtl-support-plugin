# תוסף תמיכה בשפות RTL עבור Blinko (גרסה 2.0.7+)

התוסף המתקדם ביותר לתמיכה בכתיבה מימין לשמאל (RTL) עבור אפליקציית הפתקיות [Blinko](https://blinko.mintlify.app/). תוסף זה מספק חוויית כתיבה וקריאה מקצועית בעברית, ערבית, פרסית ושפות RTL נוספות, עם זיהוי דינמי, התאמה למבנה הדף ואינטגרציה מדויקת עם העורך.

## ✨ תכונות עיקריות

### 🧠 מנוע זיהוי חכם
- **זיהוי מבוסס אסטרטגיה**: שילוב של ניתוח תווים (Character Code) וביטויים רגולריים (Regex) לדיוק מקסימלי בזיהוי השפה.
- **ערכות עיצוב דינמיות (CSS Presets)**: בחירה בין אסטרטגיות עיצוב שונות (ברירת מחדל, מינימלי, קפדני, Auto-BiDi או מצב ניפוי שגיאות).
- **עיבוד אוטומטי**: מנגנון Mutation Observer בעל ביצועים גבוהים הסורק את התוכן בזמן אמת ללא פגיעה במהירות האפליקציה.

### 🎛️ בקרות ידניות ונקודתיות
- **כפתור ציף גלובלי (ע/א)**: הפעלה או כיבוי מיידי של לוגיקת ה-RTL בלחיצה אחת.
- **מנהל הקשר בריחופ (Hover Context)**: ריחוף מעל כל פסקה חושף כפתור `⇄` המאפשר להפוך את כיוון הטקסט של אותו אלמנט ספציפי.
- **תפריט הקשר (Context Menu)**: לחיצה ימנית על בלוק טקסט מאפשרת גישה לפעולות RTL ממוקדות.

### 📝 שליטה בעורך ובתוכן מעורב
- **אופטימיזציה לעורך Vditor**: 
  - **הגנה על רשימות משימות**: מניעת קריסה של פריטי רשימה לשורות אופקיות בעת החלת RTL.
  - **מצב Markdown גולמי (SV Mode)**: זיהוי דו-כיווני חכם לכל שורה בנפרד השומר על ביצועי העורך ומיישר נכון שורות מעורבות.
  - **תצוגה מקדימה ופיצול מסך**: אינטגרציה עמוקה עם כל מצבי התצוגה של Vditor.
- **מיירט הדבקה חכם (Paste Interceptor)**: מזהה תוכן מעורב (עברית ואנגלית) בעת הדבקה ומציע לפצל את הבלוקים או לעטוף אותם בתווי בידוד יוניקוד (`U+2067`).

### 📱 חוויית משתמש רספונסיבית
- **מצב תצוגת מובייל**: עיצוב מותאם למסכים קטנים, המבטיח שסרגלי צד וכותרות לא יחרגו מהמסך במצב RTL.
- **דיבאגר ויזואלי**: הדמיה בזמן אמת של כיווני הטקסט שזוהו וטווחי האלמנטים לצורך פתרון בעיות מתקדם.
- **מצב כהה (Dark Mode)**: סנכרון מלא עם ערכת הנושא של Blinko, כולל היפוך צבעים ייעודי לאינדיקטורים של RTL.

## 🎨 ערכות עיצוב מובנות

התוסף כולל כעת ערכות CSS ייעודיות לתרחישי קריאה ופריסה שונים:

| ערכת עיצוב | תיאור |
| :--- | :--- |
| **ברירת מחדל** | תמיכה מאוזנת ב-RTL לכתיבת פתקיות כללית. |
| **קריאה בעברית (Long-Form)** | טיפוגרפיה אופטימלית, מרווח שורות (1.85) ומשקל גופן המותאם לקריאת מסמכים ארוכים. |
| **BiDi מעורב** | בידוד אוטומטי של הכיוון לכל פסקה - אידיאלי להערות טכניות המשלבות עברית ואנגלית. |
| **רשת כרטיסים (Card Grid)** | מיועד ספציפית לתצוגת הלוח (Dashboard) ולפריסת ה-Masonry. |
| **RTL מינימלי** | תיקוני כיוון ויישור בלבד ללא שינויי פריסה מבניים. |

## 🚀 תחילת עבודה

1. **התקנה**: הוסף את התוסף למופע ה-Blinko שלך.
2. **הפעלה**: לחץ על הכפתור הצף **ע/א** (בפינה הימנית העליונה) כדי להפעיל את המנוע.
3. **הגדרה**: היכנס לפאנל ההגדרות כדי:
   - להתאים את **רגישות הזיהוי** (סף של 10% עד 40%).
   - לקבוע את **מספר התווים המינימלי** לזיהוי.
   - לבחור את **ערכת העיצוב (Preset)** המועדפת עליך.
   - להפעיל **טיפול בתוכן מעורב** לטקסט דו-כיווני מתקדם.

## ⚙️ הגדרות והתאמה אישית

### רגישות זיהוי
- **גבוהה (10%)**: מפעיל עיצוב RTL גם עם מילים בודדות בעברית/ערבית.
- **בינונית (15%)**: מאוזן להערות המשלבות שפות.
- **נמוכה (25%)**: מפעיל RTL רק אם רוב הבלוק הוא בשפת RTL.

### מערכת עיצוב דינמית
התוסף מאפשר להתאים אישית את מחלקות ה-CSS המוזרקות לפתקיות. ניתן להשתמש ב-**Dynamic CSS Presets** כדי לעבור בין:
- **Strict Mode**: דריסות בעלות ספציפיות גבוהה לפריסות מורכבות.
- **Auto BiDi (Plaintext)**: מסתמך על לוגיקת ה-`unicode-bidi: plaintext` המובנית בדפדפן.
- **Debug Mode**: מסמן בלוקים של RTL במסגרת סגולה לצורך בדיקה.

## 🎯 פרטים טכניים

### בוררי יעד (Selectors)
התוסף פועל כברירת מחדל על האזורים הבאים:
- `.markdown-body` (תוכן הפתקית)
- `.vditor-reset` (עורך חי / תצוגה מקדימה)
- `.vditor-preview` (תצוגה מקדימה בפיצול מסך)
- `textarea`, `[contenteditable="true"]` (אזורי קלט)
- `li`, `p`, `div`, `blockquote` (בלוקים של טקסט)

### שפות נתמכות
- **עברית**: `\u0590-\u05FF`
- **ערבית**: `\u0600-\u06FF`
- **פרסית**: `\u0750-\u077F`
- **שפות נוספות**: סורית, תאנא (Thaana), N'Ko וערבית מורחבת.

## 🏗️ בנייה ופיתוח

```bash
# שכפול המאגר
git clone https://github.com/Daniel-OS01/blinko-rtl-support-plugin.git
cd blinko-rtl-support-plugin

# התקנת תלויות (דורש Bun)
bun install

# הרצת שרת פיתוח
bun run dev

# בניית גרסת הפצה (הקבצים ייוצרו בתיקיית /release)
bun run build:prod
```

## 📋 מה חדש (גרסה 2.0.7)
- **תכונה**: הוספת מערכת **Dynamic CSS Presets** לפאנל ההגדרות.
- **תיקון**: פתרון בעיית קריסת רשימות המשימות ב-Vditor.
- **שיפור**: שדרוג מצב ה-Markdown הגולמי (SV Mode) עם הגנה דו-כיוונית לכל שורה.
- **ארכיטקטורה**: ארגון מחדש של הלוגיקה לשימוש ב-`RTLService` מרכזי לניהול מצב.
- **ממשק**: הוספת ערכות עיצוב ייעודיות ל"קריאה ארוכה בעברית" ול"רשת כרטיסים".
