## 2025-02-19 - Accessibility of icon-only toggle buttons\n**Learning:** Relying solely on `title` attributes for icon-only buttons (like the floating manual toggle or 'show/hide' password toggles) is insufficient for screen readers. Furthermore, buttons that act as toggles must convey their active state using `aria-pressed`.\n**Action:** Always pair a descriptive `aria-label` with `aria-pressed` (true/false) on icon-only toggle buttons. If creating the element programmatically (e.g., via `document.createElement`), use `setAttribute('aria-pressed', ...)` rather than assigning it like a property.
